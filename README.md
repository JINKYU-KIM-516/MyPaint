# 칠판 그리기 (DirectX 11)

DirectX 11로 만든 간단한 칠판 그리기 프로그램입니다.

## 기능
- 칠판 위에서 마우스 왼쪽 버튼을 누른 채로 움직이면 그림이 그려집니다.
- 색상 선택: 흰색, 노랑, 빨강, 파랑, 지우개
- 굵기 선택: 얇게, 보통, 굵게
- **저장** 버튼: 현재 칠판을 `save.dat` 파일로 저장
- **불러오기** 버튼: `save.dat` 파일을 읽어서 칠판에 다시 보여줌
- **전체 지우기** 버튼: 칠판을 깨끗하게 지움

## 실행 방법
1. `MyPaint.sln`을 Visual Studio 2022로 엽니다.
2. F5로 실행합니다.

(`Shader.hlsl` 파일이 실행 위치에 있어야 합니다. 빌드하면 실행 파일 폴더로 자동 복사됩니다.)

## 파일 구성
| 파일 | 설명 |
|---|---|
| main.cpp | 윈도우 생성, 버튼, 마우스 입력 처리 |
| Graphics.h / .cpp | DirectX 11 초기화, 텍스처, 렌더링 |
| Canvas.h / .cpp | 칠판 픽셀 데이터, 선 그리기, 저장/불러오기 |
| Shader.hlsl | 텍스처를 화면에 출력하는 셰이더 |

## 구현 방법
- 칠판 크기만큼 픽셀 배열(`unsigned int`)을 만들고, 마우스가 지나간 곳에 원을 찍어서 그림을 그립니다.
- 마우스를 빨리 움직이면 점이 끊겨서, 이전 위치와 현재 위치 사이를 이어서 원을 찍도록 했습니다.
- 픽셀 배열이 바뀌면 `Map / Unmap`으로 DYNAMIC 텍스처에 복사하고, 화면 크기의 사각형에 텍스처를 입혀서 출력합니다.
- 저장은 가로, 세로 크기와 픽셀 데이터를 그대로 바이너리 파일로 씁니다. 불러오기는 반대로 읽어서 픽셀 배열에 넣습니다.
- 지우개는 칠판 배경색으로 칠하는 방식입니다.
